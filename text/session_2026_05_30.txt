  Part B — Nodata analysis
    • Load tiles (S2L2A: sample%, S1RTC: sample%, DEM: 100%)
    • For each tile split into 196 patches of 16×16 pixels, compute nodata
      fraction per patch
    • Nodata convention:
        S2L2A  → pixel == 0  (standard S2 nodata after harmonisation)
        S1RTC  → np.isnan    (orbit swath boundary)
        DEM    → np.isnan OR pixel == 0  (ocean / missing elevation)
    • Classify patches:
        clean    : nodata_frac == 0
        fillable : 0 < nodata_frac < 1%     ← these will be NN-filled in tokeniser
        partial  : 1% ≤ nodata_frac < 50%
        bad      : nodata_frac ≥ 50%        ← bad token, masked at training time
    Output → csvs/dataset_nodata.csv

WHAT WE IMPLEMENTED — NN-fill in precompute_terramind.py
────────────────────────────────────────────────────────────────────────────────

Changes to precompute_terramind.py:

  1. New import:
       from scipy.ndimage import distance_transform_edt

  2. New constants (added alongside IMAGE_SIZE / TOKEN_SIZE):
       N_SIDE          = 14   (IMAGE_SIZE // TOKEN_SIZE)
       FILLABLE_THRESH = 0.01

  3. New function _nn_fill_and_sanitize(arr, modality):
       • Detects nodata pixels (S2: ==0; S1/DEM: isnan)
       • For each of 196 patches: if 0 < nodata_frac < 1% → mark for NN-fill
       • Applies distance_transform_edt to copy value from nearest valid neighbour
         into all marked pixels
       • Calls np.nan_to_num(nan=0.0) to replace any remaining NaN with 0
         (covers S1/DEM patches with ≥1% nodata — encoder never sees NaN)
       • Fast path: returns original array unchanged if no nodata pixels at all

  4. _load_tif() gains a modality= parameter:
       if modality is not None: arr = _nn_fill_and_sanitize(arr, modality)

  5. _TifDataset gains modality= in __init__, passes it to _load_tif in __getitem__

  6. process_temporal: _TifDataset(..., modality=modality)
     process_static:   _load_tif(..., modality=modality)

────────────────────────────────────────────────────────────────────────────────
DESIGN DECISIONS
────────────────────────────────────────────────────────────────────────────────

Q: Should tiles with >50% bad patches be filtered inside precompute_terramind.py?
A: No. By design, a separate deletion step will remove such tiles before tokenisation
   (analogous to what was done for S2 via the cloudy tile filter). The tokeniser does
   not need to check for this.

Q: What happens to patches with ≥1% nodata in S1/DEM?
A: They are NOT NN-filled (fill quality degrades for large nodata regions). Instead,
   remaining NaN is replaced with 0.0 so the encoder receives finite input. Those
   tokens will be garbage but are masked at training time.

Q: Why pixel==0 as nodata for S2L2A?
A: Post-harmonisation (+1000 DN added to pre-2022 tiles), valid S2 reflectance is
   always ≥ 1. Pixel value 0 is the standard ESA S2 nodata sentinel and also means
   "no observation" in the original download.
